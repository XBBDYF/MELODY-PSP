# 确认键互换与主题适配

2026-11-11开发构建新增设置“确认键”：跟随系统 / ○确认×取消 / ×确认○取消。新数据保存在应用目录buttons.cfg，旧程序不一定提供此能力。

## 输入

程序在主线程采样入口完成一次物理→语义转换。主题的 `k.confirm`、`k.back` 仍分别表示确认、取消；不要根据确认偏好再次互换输入位。raw bit常量也只在语义输入中使用。
系统联网Utility由固件直接读物理键，继续遵循系统偏好。手动应用设置不更改系统配置。

## 提示

```lua
local hint = ui.button_hint or function(s) return s end
ui.label(16, 240, 448, hint("○ 确认  × 返回"), 0, "#FFFFFF")
```

只对静态操作提示转换一次，不包装歌曲、歌手、搜索查询、歌词或已经转换过的提示。

模型提供：

- `confirm_key`：实际物理确认键标记。
- `cancel_key`：实际物理取消键标记。
- `button_cross_confirm`：1=叉确认，0=圆圈确认。

这三个字段是说明用途，不代表主题应二次改输入。若自行组合提示，直接用模型字段，不再调用button_hint二次转换。

## 验证

测试中应覆盖两种模式、长按只有一次按下边沿、两个键同时按、切换设置当帧无误触、提示与动作相符，以及歌曲/查询/歌词原文中的○/×保持不变。

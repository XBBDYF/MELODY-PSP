# 搜索页设计（输入法 · 历史 · 推荐）

搜索页从「一个键盘 + 五个写死的歌手」改成了三块可交互区域：
**输入框（含输入法 preedit）**、**第一行（候选 / 历史）**、**第二行（推荐 / 联想）**。
本文记录布局、按键与各皮肤的实现方式。

---

## 1. 原生界面（`ui.c:screen_search`）

```
┌──────────────────────────────────────────────────────────────┐
│ 搜索                                          3 首结果        │  nav (0..28)
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 🔍 已上屏文本 + preedit(强调色)                [拼音]     │ │  y=34..64
│ └──────────────────────────────────────────────────────────┘ │
│  1.中国   2.中   3.钟 …            ← 输入法候选（有 preedit） │  y=68..88
│  （无 preedit 时这一行变成：历史 晴天 | 历史 周杰伦 | …）      │
│  推荐 周杰伦 | 邓紫棋 | 林俊杰 …   ← 推荐搜索                 │  y=94..114
│  [q][w][e]…                        ← 键盘（3 行，9/10 列）     │  y=120..204
│  ○ 上屏 · △ 删字母 · □ 中/日 · ←→ 选词                        │  y=205
└──────────────────────────────────────────────────────────────┘
```

- 输入框右侧在编辑态显示模式角标「拼音 / 假名」；
- 候选优先占第一行，没有候选时显示历史（最多 4 条）；
- 第二行有联想候选时显示联想，否则显示推荐（最多 6 个）；
- 键盘几何不变（`KB_Y0=120`），所以不影响旧截图与主题模板的坐标约定。

### 按键

| 按键 | 输入态 | 结果态 |
|---|---|---|
| ↑↓←→ | 在「键盘 / 候选 / 推荐」三块之间移动 | 移动列表选择 |
| ○ | 上屏候选；在推荐/历史上则直接搜索 | 播放 |
| △ | 有输入法输入时删一个字母；否则进联想面板 | 回到输入态 |
| □ | 切换 拼音 / 假名 | 下载当前歌曲 |
| L / R | 候选内左右移（行内） | 切换搜索分类 |
| SELECT | 清空输入（含输入法状态） | 进入输入态并清空 |
| × | 返回首页 | 返回首页 |

> L/R 从「切分类」改为只在结果态切分类：输入态的 L/R 要留给候选/推荐横向移动，
> 否则和输入法选词冲突。

## 2. 皮肤

皮肤通过 `skin_runtime` 的模型字段拿到同样的数据：

| 字段 | 含义 |
|---|---|
| `ime_mode` | 1 = 拼音，2 = 假名 |
| `ime_active` | 1 = 有未上屏输入 |
| `ime_pre` | preedit 文本（拼音字母或平假名） |
| `ime_candidates` | 候选数组（最多 6 个） |
| `ime_selected` | 当前候选（1 起） |
| `search_history` | 搜索历史数组（最多 4 条，新→旧） |
| `search_chips` | 推荐搜索数组（最多 6 条） |
| `chip_row` | 0 = 键盘/结果，1 = 第一行，2 = 推荐行 |
| `chip_selected` | 当前 chip（1 起） |

### metro（默认主题）

```
搜索框 y=63..93，白色底；preedit 用强调色接在 query 后面，右上角「拼音/假名」
第一行 y=99..119：候选（选中填色）或 历史（"历史 xxx"）
第二行 y=119..139：推荐（选中填色）
联想候选仍占第二行，但只在没有输入法输入时出现
键盘仍在 y=145 起（与旧版一致）
底栏：○ 上屏 · △ 删字母 · □ 中/日
```

### xmb

版式与 metro 相同，只是字体/颜色/分隔线走 XMB 风格；
搜索框是 `icon + 文本`，preedit 紧跟 query，模式角标放右侧同一行。

### paper

paper 主题没有独立的 `search` 页面函数，搜索页回退到原生界面，
因此自动获得「候选 / 历史 / 推荐」三块布局，不需要额外改。

### 其它皮肤

`metro_day` 与 `metro` 共用同一份 Lua（只切配色），`ocean/mint/ruby/night/daylight`
是纯配色皮肤、没有自定义 search 页，全部回退原生界面。

## 3. 推荐搜索怎么来的

`search_chips_build()`（`src/search_chips.c`）：

1. 最近播放的歌手（去重，最多取若干个）；
2. 收藏歌曲的歌手（补位，去重）；
3. 内置兜底：周杰伦 / 林俊杰 / 邓紫棋 / 陈奕迅 / 薛之谦 / 李荣浩。

没有个人数据时就是这 6 个兜底项，所以页面上永远有东西可点。
生成时机：进入搜索页、每次搜索完成、写历史之后。

---

## 4. 历史怎么来的

- 每次真正发起搜索（`search_do`）时 `search_hist_push()`；
- 最多 8 条，重复词前移不重复，竖线/换行清成空格；
- 持久化在 `data.txt` 的 `H|查询词` 行，`store_save()` 写、`store_init()` 读；
- 页面上只显示前 4 条，其余仍在文件里（下次前移还会出现）。

---

## 5. 已知边界

- 输入法只在搜索页生效，其它输入（无）不需要；
- 假名转换以「词条读音」为单位，长句需要整条读音打完整才出候选；
- 词库目前 110（拼音）/ 63（日语）条，扩充方式见 `docs/IME-AND-FONTS.md`；
- 候选只显示一行 6 个，超出部分用 ←→ 移动（不做翻页）；
- 皮肤若不读新字段，只是不显示 preedit/候选，键盘输入仍然可用（原生会接管提示）。

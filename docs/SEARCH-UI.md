# 搜索页设计（输入法 · 历史 · 推荐）

搜索页由四块组成：**输入框（含 preedit 与模式角标）**、**左列（候选 / 推荐 / 联想）**、
**右列（搜索历史竖排）**、**键盘**。输入法有三种模式：拼音 / 假名 / 英文直输。

---

## 1. 三种输入模式（□ 循环切换）

| 模式 | 角标 | 行为 |
|---|---|---|
| 拼音 | 拼音 | 字母进 preedit；候选第一行先给**同音节单字**，再给词；○ 上屏；空格上屏当前候选，否则原样上屏 |
| 假名 | 假名 | 字母先转平假名（`kitte`→きって），再按读音查汉字；候选最后永远有「假名原文」「片假名」 |
| **英文直输** | 英文 | 字母**直接写进搜索框**，不产生 preedit；适合搜英文歌名或没转换成功的拼音 |

> 之前没有英文模式，字母全被输入法吃掉，看起来像"打不了英文"——现在 □ 按两次即可。
> 搜索框在**有 preedit 时不显示占位文案**（以前会出现"歌曲、歌手、歌单"与拼音叠在一起）。

## 2. 原生界面版式（`ui.c:screen_search`）

```
┌──────────────────────────────────────────────────────────────┐
│ 搜索                                          3 首结果        │
│ ┌──────────────────────────────────────┐ ┌───────────────┐   │
│ │ 🔍 已上屏文本 + preedit（强调色）     │ │ 历史          │   │
│ └──────────────────────────────────────┘ │ ┌───────────┐ │   │
│  联想 中国风｜中国话｜中国魂 …            │ │ 晴天      │ │   │
│  候选 中｜国｜钟｜忠｜终 …  ‹  ›          │ │ 周杰伦    │ │   │
│  [q][w][e]…  键盘（3 行）                 └───────────────┘   │
│  ○ 上屏 · △ 联想 · □ 中/日/英 · ← 删除                        │
└──────────────────────────────────────────────────────────────┘
```

- **上排（y=68）**：联想。来源优先级：本地词库补全（`ime_assoc`，以上屏文字为前缀的词）→
  在线联想（`api_request_suggest`）→ 没有输入时变成「推荐」；
- **上排也可滚动**：一屏 3 个，`<` `>` 提示（`chip_off` 窗口）；上排最右再按 → 进右侧历史列；
- **下排（y=94）**：候选。一屏显示 4 个，**左右可滚动**（`ime_off` 窗口，两侧 `<` `>` 提示），
  候选上限 32 个，所以 `chen` 能一路翻到「趁、衬、谌…」后面的字词；
- **右列**：搜索历史，`-3` 焦点可上下选择，`○` 直接搜索；
- 上屏（`○` 选候选）后**立刻联想**：本地词库补全 + 在线联想一起刷新；
- 只有拼音/字母时也会联想（在线联想 + 推荐兜底）。

### 焦点与按键

| 焦点行 | 进入方式 | 左右 | 上下 | ○ |
|---|---|---|---|---|
| `-1` 上排（联想/推荐） | 键盘第 0 行按 ↑（有候选时先到 `-2`） | 联想/推荐横向移动 | ↑ 进历史列；↓ 到下排候选或键盘 | 搜索该项 |
| `-2` 下排（候选） | ↑ 从键盘进入；或 `-1` 按 ↓ | 候选左右移动，自动滚动窗口 | ↑ 回上排；↓ 回键盘 | **上屏到搜索框**并触发联想 |
| `-3` 右列历史 | 上排按 ↑，或键盘 ↑ 时无候选/联想 | — | ↑↓ 在历史列内移动，到底回上排 | 搜索该历史 |

**空行跳过**：没有候选时 ↑ 不会停在候选行，没有联想时也不会停在上排，
直接在「键盘 ↔ 历史列」之间跳；反之亦然。

## 3. 皮肤

| 字段 | 含义 |
|---|---|
| `ime_mode` | 1=拼音，2=假名，3=英文 |
| `ime_active` / `ime_pre` / `ime_candidates` / `ime_selected` | 输入法状态与候选 |
| `search_history` | 历史（新→旧，最多 4 条） |
| `search_chips` | 推荐（最多 6 条） |
| `chip_row` | 0=键盘/结果，1=左列第一行，2=联想行，3=历史列 |
| `chip_selected` / `hist_selected` | 当前选中项（1 起） |

### metro / metro_day

- 搜索框（y=63..93）：preedit 用强调色接在 query 后，右上角「拼音 / 假名 / 英文」；
- 左列：y=99 候选（最多 5 个，62px 宽）或「推荐 + 4 个」；y=119「联想 + 3 个」（仅无输入法输入时）；
- 右列：x=356 起「历史」，最多 3 条，每行 15px；
- 键盘 y=145 起，底栏提示随状态变化。

### xmb

与 metro 相同结构，字体/分隔线走 XMB 风格。

### 其它皮肤

`paper / ocean / mint / ruby / night / daylight` 没有自定义 search 页 → 回退原生界面，
自动获得同样的四块布局。

## 4. 数据来源

- **历史**：`search_do()` 时 `search_hist_push()`；`data.txt` 的 `H|查询词` 行持久化；最多 8 条，
  页面显示 3～4 条；
- **推荐**：`search_chips_build()`：最近播放歌手 → 收藏歌手 → 内置兜底（周杰伦/林俊杰/邓紫棋/
  陈奕迅/薛之谦/李荣浩）；进页面或搜索完成后重建；
- **联想**：仍是 `api_request_suggest()`（网易接口），只在没有输入法输入时显示。

---

## 5. 已知边界

- 输入法只在搜索页生效；
- 假名模式不做分词，长句要整条读音打完整；
- 词库 110（拼音）/ 63（日语）条，扩充见 `docs/IME-AND-FONTS.md`；
- 候选最多 5 个一屏，超出用 ←→ 移动（不做翻页）；
- 历史列只显示前 3 条，文件里仍保留 8 条。
